# Context rent is the core metric

We report context rent in **token-turns** rather than tokens spent or money. Tokens spent is not actionable and systematically rewards short sessions; money depends on list prices and flat subscriptions, so any public number based on it is easy to dispute. Rent charges each piece of content for the turns it survived and attributes it to the injection that carried it, which stays comparable across sessions of different length and between variants. Everything else in the report is a breakdown of this one number.
