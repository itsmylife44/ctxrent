# 08: Skill and MCP attribution

**What to build:** Where a session record attributes usage to a skill or an MCP tool, that rent is reported separately so that the cost of a skill can be weighed against what it contributed.

**Blocked by:** 04.

**Status:** ready-for-agent

- [ ] Sessions carrying attribution fields report rent per skill and per MCP tool
- [ ] Sessions without those fields report the metric as unavailable, with coverage stated
- [ ] Attribution never reassigns rent that is already attributed to another carrier
- [ ] The terminal and HTML reports both show the per-skill section when available
