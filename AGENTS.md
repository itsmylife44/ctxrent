# ctxrent

A CLI that measures the context rent of coding-agent sessions and compares variants by running declared task sets. Local-only, zero runtime dependencies.

## Agent skills

### Issue tracker

Issues and specs live as markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, with label strings identical to the role names. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: root `GLOSSARY.md` and `docs/adr/`. See `docs/agents/domain.md`.
